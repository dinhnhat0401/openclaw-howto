# OpenClaw Productivity Stack

> A compact blueprint for maximizing work output.

## The stack

1. **One primary channel** you already check
2. **Explicit workspace files** (`USER.md`, `TOOLS.md`, `AGENTS.md`, `HEARTBEAT.md`)
3. **Seeded memory** with role, preferences, team, projects, and shorthand
4. **Three core automations**
   - morning briefing
   - PR review watch
   - end-of-day summary
5. **One high-value workflow**
   - PR review
   - meeting autopilot
   - inbox triage
   - research-to-decision
6. **Weekly maintenance**
   - check failures
   - prune memory
   - cut noisy alerts
   - review costs

## Rule of thumb

The best OpenClaw setups feel like:

- fewer context switches
- faster reviews
- better preparation
- less forgotten work
- more shipping

not “more AI features.”
